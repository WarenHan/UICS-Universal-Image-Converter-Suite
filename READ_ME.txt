==================================================
  UNIVERSAL IMAGE CONVERTER SUITE (UICS) v2
==================================================

WHAT THIS TOOL DOES:
--------------------
This application is a fast, portable batch image converter. It allows 
you to drop various image formats into a local queue and instantly 
convert them to a standardized format (JPG, PNG, WEBP, BMP, or TIFF).

SUPPORTED INPUT FORMATS:
------------------------
* HEIC / HEIF (.heic) - Fully supported (great for iPhone photos)
* JPEG / JPG (.jpg, .jpeg)
* PNG (.png)
* WebP (.webp)
* BMP (.bmp)
* TIFF (.tiff)


HOW TO USE:
-----------
1. UPLOAD IMAGES: 
   Click "Upload Images..." to select one or more photos. They are automatically 
   copied into the local "UICSinput" folder to keep everything organized and 
   isolated. Alternatively, you can drop files directly into the "UICSinput" folder.

2. MANAGE QUEUE:
   The files currently waiting to be converted are displayed in the live inventory 
   window. If you want to remove an individual file, right-click it and select 
   "Delete Selected File(s) From Inbox". To wipe the whole queue, click "Clear Queue".

3. SELECT OUTPUT FORMAT:
   Choose your desired target format from the dropdown menu at the bottom 
   (JPG, PNG, WEBP, BMP, or TIFF).

4. SELECT OUTPUT LOCATION (Optional):
   By default, converted files are saved into a timestamped folder right next to 
   this application (e.g., "Convert-08052026-1430"). Click "Output Location..." if 
   you want to direct the output elsewhere.

5. CONVERT:
   Click "Convert Batch". The app will process the images, clear them out of the 
   input queue upon success, and automatically open the destination folder when finished.


PORTABLE OPERATION:
-------------------
This tool requires no installation. All necessary folders ("UICSinput") are created 
automatically in the same directory where this executable lives. You can run it 
from a local drive, a flash drive, or a network share.
